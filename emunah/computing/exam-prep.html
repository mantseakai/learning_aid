🖥️ Section 3 — Computer Hardware & the CPU

⚠️ Q8 Mistake — The MICROPROCESSOR controls everything, not the Mouse

The question asked: "The ___ controls all the activities of the computer."
You chose Mouse ❌ — a mouse is an input device (it lets you point and click), but it does NOT control the computer. The Microprocessor (CPU) is the brain of the computer — it controls everything.

✗ Mouse ❌
The mouse is an input device — it sends signals TO the computer. It doesn't control it.
✓ Microprocessor (CPU) ✅
The CPU (Central Processing Unit) is the brain — it processes every instruction.
🧠
CPU / Microprocessor
The brain of the computer. Controls ALL activities and processes instructions.
Also called the "processor"
🖥️
Monitor
The screen that displays output. You see things on it.
Output device
⌨️
Keyboard
You type letters and numbers. Sends input to the computer.
Input device
🖱️
Mouse
You point, click and drag. Sends input to the computer.
Input device ← NOT the brain!
🔊
Speaker
Brings sound OUT of the computer. You hear audio through it.
Output device
🖨️
Printer
Prints documents onto paper from the computer.
Output device

💡 Easy way to remember Input vs Output:
Input = things you put INTO the computer (keyboard, mouse, joystick, microphone)
Output = things that come OUT of the computer (monitor, speaker, printer)
