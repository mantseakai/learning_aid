⚡ Section 1 — What Is Force?
A force is a PUSH or PULL on an object.
🚀
Speed Up
Force can make an object go faster!
🛑
Slow Down
Force can make an object stop or slow down.
🫸
Change Shape
Force can change the shape of an object.

Push vs Pull — Direction Matters!

👉 PUSH →→→ 📦 Object
📦 Object ←←← PULL 👈

A push moves an object away from you. A pull moves an object towards you.

🧑‍🔬 Sir Isaac Newton
🧑‍🔬

Sir Isaac Newton

The Newton (N) is the standard unit of force — named after him!

He lived in Great Britain, from 1642 to 1727.

🍎 Fun Fact: Newton discovered gravity when an apple fell on his head!
📏 The Forcemeter
📏

Forcemeter

A forcemeter is an instrument used to measure the strength of a force.

Force is measured in Newtons (N).
