🔢 Section 1 — Les Nombres 40–99

These are the tricky numbers you missed in the test. Learn the pattern — French numbers are built like little sums!

⚠️

The 3 Numbers Emunah Missed!

These three numbers have special French patterns — they are NOT built the way you might expect:

✗ 49 = "Quatre-neuf" ❌
✗ 79 = "Sixzonét-neuf" ❌
✗ 99 = "Neuf-neuf" ❌
✓ 49 = quarante-neuf ✅
✓ 79 = soixante-dix-neuf ✅
✓ 99 = quatre-vingt-dix-neuf ✅

80 quatre-vingts 4×20! quatre (4) × vingts (20s) = 80

70 = 60+10  ·  80 = 4×20  ·  90 = (4×20)+10 soixante-dix · quatre-vingts · quatre-vingt-dix

🕐 Section 2 — L'Heure (Telling the Time)

In the test you wrote "1:22 am" and "2:21 pm" — but in French class you need to answer in FRENCH! Learn the pattern below.

⚠️

How to say the time in French

Always start with Il est (= It is), then the hour, then heure(s), then the minutes.

✗ "1:22 am" ❌
✗ "2:21 pm" ❌
That's English — not French!
✓ Il est une heure vingt-deux ✅
✓ Il est deux heures vingt et un ✅
Il est [heure] heure(s) [minutes]. = It is [hour] o'clock [minutes].
1:00
Il est une heure.
It is one o'clock.
2:15
Il est deux heures quinze.
It is two fifteen.
1:22
Il est une heure vingt-deux.
It is one twenty-two.
2:21
Il est deux heures vingt et un.
It is two twenty-one.
3:30
Il est trois heures trente.
It is three thirty.
10:00
Il est dix heures.
It is ten o'clock.
💡

Special rule: "une heure" vs "heures"

1 o'clock = une heure (singular — just one hour!)
All other times = heures (plural — two hours, three hours...)

Il est une heure. (1:00) ✅
Il est deux heures. (2:00) ✅

📆 Section 4 — Les Jours & La Logique des Jours

You got two days questions wrong. Let's fix both — understanding which day comes before and after, and knowing that "dimanche" is the day for church!

⚠️

Q23: Je vais à l'église chaque ___

You chose vendredi ❌ — but Christians go to church on dimanche (Sunday).
Vendredi = Friday (the Islamic prayer day). Dimanche = Sunday (the Christian worship day).

✗ vendredi = Friday ❌
✓ dimanche = Sunday ✅ (church day!)
⚠️

Q25: Hier était lundi, demain sera ___

You chose mardi ❌ — but think it through step by step:

✗ Thinking: lundi → mardi ❌
You jumped one day forward but forgot that "hier" means YESTERDAY — so lundi was already gone!
✓ hier = lundi → aujourd'hui = mardi → demain = mercredi ✅
If yesterday was Monday, today is Tuesday, so tomorrow is Wednesday!
hier → aujourd'hui → demain yesterday → today → tomorrow
