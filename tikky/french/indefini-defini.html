4 Vrai ou Faux? ✅❌
"un → le" is for masculine nouns.
"une boîte" changes to "le boîte."
"une → la" is for feminine nouns.
"un garçon" changes to "le garçon."
"un vélo" changes to "la vélo."
"une fille" changes to "la fille."
